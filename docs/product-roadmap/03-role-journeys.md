# 3 — رحلات الأدوار والوصول المتساوي للـQR

## قاعدة المنتج

> البطاقة العامة غير الحكومية واحدة للجميع. الاختلاف في الأفعال المسموحة، لا في ملخص الحيوان العام.

لا توجد أفضلية في المسح بين المربي/الموال والوسيط التجاري والمشتري. حتى الزائر
يستطيع قراءة البطاقة العامة. الحساب يصبح مطلوبًا عند الحفظ، الطلب، الإبلاغ
المتابع، أو أي تعديل.

**قاموس هذا الفصل:**

- `breeder` = **المربي** (وتشمل التسمية الدارجة «الموال»).
- `broker` = **الوسيط التجاري** — نوع العضوية ما زال مقترحًا في FD-01.
- `buyer` = **المشتري**.

## رحلة المسح في ثلاث شاشات

### 1. المسح

- زر «امسح QR» ظاهر في الصفحة العامة ومساحات العمل.
- لا يُطلب اختيار الدور قبل المسح.
- يقرأ ماسح MawashiDZ المعرف المبهم المعتمد.
- إذا اعتُمد مقترح البطاقة الموقعة، يتحقق الماسح من الحمولة offline أيضًا.

### 2. النتيجة

تظهر أولًا:

1. نمط التحقق: إلكتروني حالي / نسخة مخزنة قديمة / توقيع offline **إذا اعتُمد**.
2. حالة الاتصال: متصل / دون إنترنت.
3. وقت الإصدار وآخر تحقق محفوظ.
4. بيانات الحيوان العامة.
5. تنبيه: «هذه بطاقة عامة غير حكومية صادرة عن MawashiDZ وليست وثيقة رسمية».

### 3. الفعل التالي

- «تحقق عبر الإنترنت».
- «أبلغ عن اختلاف».
- «افتح العرض المرتبط» إن كان عامًا.
- «سجّل الدخول لطلب الشراء» للمشتري.
- «افتح السجل» للمالك المخول.

## ما يراه الجميع

| الحقل | عام؟ | ملاحظة |
|---|---:|---|
| معرف MawashiDZ المبهم | نعم | لا يكشف معرف قاعدة أو هوية وطنية |
| النوع والجنس | نعم | عند توفرهما |
| سلالة/لون/علامات بصرية مختصرة | نعم | تساعد على اكتشاف اختلاف واضح |
| سنة/دقة الميلاد | نعم | لا تدّعي عمرًا دقيقًا إذا كان تقديريًا |
| صورة عامة معتمدة | إلكترونيًا | قد لا تُحمل offline إلا إذا خُزنت سابقًا |
| حالة البطاقة ووقت إصدارها | نعم | صالحة/قديمة/ملغاة عند الاتصال |
| مستوى التحقق | نعم | تصريح ذاتي/مراجعة وثيقة/مشاهدة ميدانية |
| اسم المالك وهاتفه وموقعه الدقيق | **لا** | بيانات خاصة |
| التشخيص والعلاج التفصيلي | **لا** | صحي حساس |
| السعر والتفاوض | عبر العرض فقط | ليس جزءًا من هوية الحيوان |

|---|---:|---:|---:|---:|---:|
| مسح البطاقة العامة | ✓ | ✓ | ✓ | ✓ | ✓ |

| تغيير سجل تاريخي | ✗ | ✗ | ✗ | ✗ | لا حذف؛ تصحيح بحدث جديد |

## رحلات بسيطة لكل شخصية

### المربي/الموال

```text
يسجل → يُقبل → يضيف حيوانًا → يطبع QR → ينشئ عرضًا → يرد على طلب → ينقل الملكية
```

الصفحة الرئيسية لمساحته تعرض: «حيواناتي»، «عروضي»، «الطلبات»، ثم المعلومات
المساندة.

### الوسيط التجاري — رحلة مقترحة

```text
قرار FD-01 → نموذج تفويض مدقق → تسجيل مستقل → أدوات تجارية محدودة → توثيق الصفقة
```

هذه الرحلة ليست صلاحية حالية. لا يرث الوسيط أدوات المزرعة، ولا يكتب على حيوان
الغير قبل اعتماد نوع العضوية ونموذج تفويض خادمي ومدقق. ولا يستطيع بعد ذلك تغيير
أصل الحيوان أو أحداثه السابقة.

### المشتري

```text
يمسح/يبحث دون حساب → يرى البطاقة العامة → يسجل للدخول → يحفظ/يطلب → يقبل النقل
```

المسح العام لا يضع حاجز تسجيل قبل معلومة الثقة الأساسية.

### الطبيب البيطري

```text
ملف مهني مراجع → موافقة صاحب الحيوان → يضيف حدثًا صحيًا محدد المصدر → يبقى التاريخ
```

لا يعدّل الطبيب المالك أو السعر أو العرض. أي «شهادة» تحتاج سلطة وصياغة قانونية
واضحة قبل إطلاقها.

### مدير الولاية

```text
يراجع ضمن ولايته → يعالج البلاغ → يصعّد عند الحاجة → كل فعل يدخل سجل التدقيق
```

لا يرى ولايات أخرى، ولا يمنح نفسه دورًا، ولا يحذف التاريخ.

## حالات الفراغ المقترحة

| الحالة | النص | الإجراء |
|---|---|---|
| مربي بلا حيوانات | «ابدأ بإضافة أول حيوان» | إضافة حيوان |
| مربي بلا عروض | «اختر حيوانًا وأنشئ أول عرض» | إنشاء عرض |
| مشتري بلا طلبات | «امسح QR أو تصفح الحيوانات القريبة» | مسح / بحث |
| طبيب بلا حالات | «أكمل ملفك المهني ليتم إسناد الحالات» | إكمال الملف |
| مدير بلا مهام | «لا توجد مراجعات عاجلة» | نشاط الولاية |
| Offline بلا نسخة | «هذه البطاقة لم تُفتح على هذا الهاتف من قبل» | حاول عند الاتصال |
