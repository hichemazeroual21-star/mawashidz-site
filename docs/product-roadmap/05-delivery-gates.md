# 5 — بوابات التسليم والقياس والتوقف

## لماذا نحتاج بوابات؟

نجاح الكود لا يثبت نجاح المنتج. البوابة تمنع الانتقال لأن الشاشة جميلة بينما:

- المستخدم الحقيقي لا يحتاجها.
- التشغيل الميداني غير موجود.
- الصياغة القانونية غير محسومة.
- المسار لم يُختبر حيًا.

## تصنيف كل عنصر

| التصنيف | المعنى |
|---|---|
| Must | لا تخرج المرحلة بدونه |
| Should | مهم بعد ثبات الأساس |
| Could | يبنى عند وجود دليل استعمال |
| Future | ليس التزامًا، ويحتاج قرارًا جديدًا |
| NON-GOAL | ممنوع في الأفق الحالي |

## بوابات عامة لكل مرحلة

### 1. بوابة المستخدم

- [ ] مستخدم محدد ومشكلة محددة.
- [ ] المهمة قابلة للشرح في جملة.
- [ ] اختبار على هاتف حقيقي واتصال ضعيف.
- [ ] حالة فراغ وفشل واسترجاع واضحة.

### 2. بوابة الصلاحيات والخصوصية

- [ ] مصفوفة القراءة/التعديل معتمدة.
- [ ] RLS/RPC يفرضانها.
- [ ] لا بيانات خاصة في logs أو QR أو الإشعارات العامة.
- [ ] تبديل الحساب وفشل الجلسة fail-closed.

### 3. بوابة التشغيل

- [ ] مالك تشغيلي للعملية.
- [ ] زمن استجابة وتصعيد.
- [ ] سجل تدقيق.
- [ ] نسخة احتياطية واسترجاع مجرّب.
- [ ] دعم وحل نزاع معروفان قبل إطلاق التجارة.

### 4. بوابة الدليل

- [ ] اختبارات آلية.
- [ ] Smoke حي من البداية إلى النهاية.
- [ ] لقطة/فيديو أو سجل نتيجة قابل للمراجعة.
- [ ] لا يُستبدل الاختبار المحلي بادعاء إنتاج.

## بوابات تجارية وقانونية مقترحة

هذه البوابات **توصية** ناتجة عن مراجعة استثمارية خارجية، وليست تعديلًا صامتًا
للدستور.

| قبل بناء | الدليل المطلوب |
|---|---|
| سوق وطني | تجربة يدوية في نطاق صغير وبائعون ومشترون فعليون |
| خدمة مدفوعة | عقد/شروط وإلغاء واسترجاع ومسؤولية واضحة |
| QR موقّع offline أو طباعة واسعة | حاجة تشغيلية مثبتة، ADR، وصياغة تمنع الادعاء الرسمي |
| سجل صحي | طبيب شريك، موافقة، مصدر كل معلومة، وحدود المسؤولية |
| الدفع/العربون | مستشار قانوني وشريك دفع مرخص |
| اللوجستيك | معاملات وشركات نقل فعلية واتفاق مسؤوليات |
| توسع الولايات | نجاح قابل للقياس في الولاية التجريبية |

### Stop rule تجاري مقترح

قبل استثمار كبير في السوق أو اللوجستيك أو الدفع:

- ثلاثة عملاء دافعين أو التزامات شراكة قابلة للتحقق.
- تنفيذ يدوي ناجح دون استبدال حيوان أو نزاع غير محلول.
- هامش مساهمة موجب بعد احتساب العمل والاسترجاع.

هذا حد قرار للمؤسس، لا حقيقة إحصائية. إذا لم يتحقق، تُحفظ المنصة ويُوقف التوسع
بدل تعويض نقص الطلب بمزيد من البرمجة.

## مقاييس قليلة ومفيدة

### العضوية والعمليات

- نسبة إكمال التسجيل.
- زمن المراجعة الوسيط.
- نسبة الطلبات التي تحتاج معلومات إضافية.
- زمن حل التذكرة.
- نسبة رسائل البريد المسلمة.

### الحيوان وQR

- عدد الحيوانات ذات بطاقة صالحة.
- نسبة إنشاء بطاقة دون مساعدة.
- نجاح المسح على أول محاولة.
- المسح online مقابل offline.
- نسبة البطاقات القديمة.
- بلاغات اختلاف الحيوان/الصورة/QR.
- زمن إلغاء وإعادة إصدار بطاقة.

### السوق

- عروض نشطة حقيقية، لا حسابات تجريبية.
- بحث → فتح عرض → طلب شراء.
- زمن رد البائع.
- طلبات مكتملة يدويًا.
- بلاغات ونزاعات لكل 100 طلب.
- معاملات أدت إلى حدث نقل ملكية.

### الجودة

- أخطاء JavaScript.
- فشل API حسب المسار.
- Core Web Vitals على الهاتف.
- نسبة نجاح sync/restore.
- حوادث تسرب صلاحية أو ولاية.

## بوابات الادعاءات

| الحالة الفنية | العبارة العامة |
|---|---|
| تصميم أو mock | «تصور/عرض توضيحي» |
| مدرج في الخارطة | «قادم» |
| يعمل محليًا فقط | لا يُقال «متاح» |
| نشر دون Smoke كامل | «قيد التحقق» |
| exit criteria + Smoke حي | «متاح» مع حدود دقيقة |

## سجل المخاطر المختصر

| الخطر | الاحتمال | الأثر | الاستجابة |
|---|---|---|---|
| الخلط مع الهوية الرسمية | متوسط | عالٍ | لغة قانونية وحدود ظاهرة |
| نسخ/نقل QR | عالٍ | متوسط/عالٍ | علامات بصرية، إبلاغ، إلغاء |
| بيانات offline قديمة | عالٍ | متوسط | وقت تحديث و`stale` إلزامي |
| نقص مشغلين ميدانيين | عالٍ | عالٍ | نطاق تجريبي وشريك محلي |
| سوق بلا سيولة | عالٍ | عالٍ | معاملات يدوية قبل البرمجة |
| معلومات صحية خاطئة | متوسط | عالٍ | مصدر/موافقة/صلاحيات ولا ضمان طبي |
| توسع مبكر | متوسط | عالٍ | بوابات مرحلة وStop rules |
| تراكم CSS/تعقيد الواجهة | عالٍ حاليًا | متوسط | تحسين تدريجي واختبارات baseline |

## Definition of Done

الميزة منتهية فقط عندما:

1. يعمل happy path والفشل والاسترجاع.
2. الصلاحيات مختبرة على الخادم والواجهة.
3. الهاتف واللغة العربية وحالة offline مختبرة عند انطباقها.
4. القياس والتدقيق موجودان.
5. الوثائق والادعاء العام مطابقان للحقيقة.
6. يوجد rollback أو مسار إيقاف آمن.
